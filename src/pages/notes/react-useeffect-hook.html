React useEffect hook

useEffect përdoret për side effects — fetch, event listeners, dhe çdo gjë që nuk është “pure” në render.

Përse përdoret?

React useEffect hook përdoret për side effects.

Pure functions

Në functional programming paradigm kemi të bëjmë me një pure function kur një funksion bazohet vetëm në parametrat e tij për të kthyer vlerë, dhe gjithmonë për të njëjtat parametra kthen të njëjtën vlerë. 

function addNumbers(a, b) {
  return a + b;
}
console.log(addNumbers(1,2))//printon 3
console.log(addNumbers(1,2))//printon 3
console.log(addNumbers(2,5))//printon 7
console.log(addNumbers(2,5))//printon 7

Side effects

Në functional programming paradigm kemi të bëjmë me një side effect kur një funksion nuk bazohet vetëm në argumentat që i janë dhënë për të kthyer një rezultat. 

function addRandomVal(a) {
  return a + Math.random();
}
console.log(addRandomVal(2)); //printoi 1.6116067558854512
console.log(addRandomVal(2)); //printoi 1.8476619014999933
console.log(addRandomVal(2)); //printoi 1.5212097903173378

Në programim, në situata të ndryshme na duhet të përdorim side effects, pasi aplikacioni jo gjithmonë është statik. useEffect në React e përdorim për side effects të ndryshëm si fetching an API, registering DOM event listeners, etj.

Anatomia e useEffect

useEffect(() => {
    // Mounting
    return () => {
        // Cleanup function
    }
}, [/*Updating*/])

Si funksionon

useEffect importohet nga libraria e React:

import { useEffect } from "react";

Edhe si çdo hook, thërritet vetëm brenda functional components në React. 

import { useEffect } from "react";

export default function App() {

  useEffect(() => {});

  return <div className="App" />;
}

Siç shikohet, useEffect merr si parametër një funksion, të cilin do ta ekzekutojë në çdo render.

useEffect thërritet sa herë komponenti bëhet render / re-render

import { useEffect } from "react";
export default function App() {
  useEffect(() => {
    console.log("useEffect called");
  });
  return <div className="App" />;
}

Herën e parë që komponenti do të bëhet mount, useEffect do të thërritet dy herë:

Sa herë të shkaktojmë re-render në këtë komponent, aq herë useEffect do të thërritet. Shikoni shembullin e mëposhtëm: 

import { useEffect, useState } from "react";
export default function App() {
  const [count, setCount] = useState(0);
  useEffect(() => {
    console.log("useEffect called");
  });
  return (
    <div className="App">
      <button onClick={() => setCount(count + 1)}>Increase Count</button>
    </div>
  );
}

Nëse butoni “Increase Count” shtypet 8 herë, “useEffect called” do të printohet 10 herë (2 herë për initial render edhe 8 herë sepse setCount thërritet).

Dependency array

Parametri tjetër që useEffect merr është një array me dependencies. Dependencies është një array me emrat e variablave që nëse ndryshojnë, useEffect do të thirret.

Nëse ky array është bosh, atëherë useEffect do të thërritet vetëm në initial render, por nuk do të ri-thërritet më nga asnjë ndryshim në state. 

import { useEffect, useState } from "react";
export default function App() {
  const [count, setCount] = useState(0);
  useEffect(() => {
    console.log("useEffect called");
  }, []);
  return (
    <div className="App">
      <button onClick={() => setCount(count + 1)}>Increase Count</button>
    </div>
  );
}

Butoni “Increase Count” është klikuar shumë herë por, “useEffect called” printohet vetëm 2 herë.

Nëse do të shtonim edhe një buton tjetër, që ndryshon një tjetër state variable: 

import { useEffect, useState } from "react";
export default function App() {
  const [count, setCount] = useState(0);
  const [count2, setCount2] = useState(0);
  useEffect(() => {
    console.log("useEffect called");
  }, []);
  return (
    <div className="App">
      <button onClick={() => setCount(count + 1)}>
        Increase Count
      </button>
      <button onClick={() => setCount2(count2 + 1)}>
        Increase Count 2
      </button>
    </div>
  );
}

Mund të zgjidhnim se cila nga variablat mund të shkaktonte thërritjen e useEffect: 

import { useEffect, useState } from "react";
export default function App() {
  const [count, setCount] = useState(0);
  const [count2, setCount2] = useState(0);
  useEffect(() => {
    console.log("useEffect called");
  }, [count]);
  return (
    <div className="App">
      <button onClick={() => setCount(count + 1)}>
        Increase Count
      </button>
      <button onClick={() => setCount2(count2 + 1)}>
        Increase Count 2
      </button>
    </div>
  );
}

Mund të ketë disa useEffects, me dependency arrays të ndryshme: 

import { useEffect, useState } from "react";
export default function App() {
  const [count, setCount] = useState(0);
  const [count2, setCount2] = useState(0);
  useEffect(() => {
    console.log("useEffect called");
  }, [count]);
  useEffect(() => {
    console.log("useEffect called");
  }, [count2]);
  return (
    <div className="App">
      <button onClick={() => setCount(count + 1)}>
        Increase Count
      </button>
      <button onClick={() => setCount2(count2 + 1)}>
        Increase Count 2
      </button>
    </div>
  );
}

Cleanup function

Nga anatomia e useEffect pamë që useEffect mund të shkruhet me një return function, i cili do të shërbejë për cleanup. Ky funksion do të thërritet përpara se useEffect të thërritet prapë, në re-renderin e ardhshëm.

Shembull: useEffect mund të përdoret për të regjistruar event listeners: 

import "./styles.css";
import { useEffect } from "react";

export default function App() {
  function handleKeyPress(event) {
    console.log(event.key);
  }
  useEffect(() => {
    window.addEventListener("keypress", handleKeyPress);
  });
  return (
    <div className="App">
      <h1>Hello CodeSandbox</h1>
      <h2>Start editing to see some magic happen!</h2>
    </div>
  );
}

Do të donim që event listener të regjistrohej vetëm një herë, edhe jo në çdo re-render. Në këtë rast duhet të shtojmë cleanup function: 

import "./styles.css";
import { useEffect } from "react";

export default function App() {
  function handleKeyPress(event) {
    console.log(event.key);
  }
  useEffect(() => {
    window.addEventListener("keypress", handleKeyPress);
    return () => window.removeEventListener("keypress", handleKeyPress);
  }, []);
  return (
    <div className="App">
      <h1>Hello CodeSandbox</h1>
      <h2>Start editing to see some magic happen!</h2>
    </div>
  );
}

Kështu, sa herë që komponenti bëhet re-render, event listener do të hiqet dhe do të shtohet sërish — kështu do të kemi gjithmonë vetëm një event listener.
