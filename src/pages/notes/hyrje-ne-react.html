React është një librari

Librari → Një set klasash dhe funksionesh për t’i lehtësuar punën programuesit.

Framework → Bazë kodi nga ku fillon ndërtimi i aplikacionit. (Të “detyron” të ndjekësh një strukturë të caktuar.)

Më shumë: Library vs Framework Comparison · Tania Rascia — What is React

React është librari JS dhe jo framework, pasi nuk të detyron të përdorësh një strukturë të caktuar për të ndërtuar një projekt — ndryshe nga Angular p.sh., i cili që në implementim të inicializon një sërë mjetesh për format, testet, network requests etj. React, në anën tjetër, të lejon të zgjedhësh vetë si dëshiron t’i zgjidhësh këto probleme.

Pothuajse çdo gjë në React është komponent

Components (Tania Rascia)

Shpjegim paraprak:

DOM (Document Object Model) është një pikë komunikimi e një faqeje web me programet që mund ta ndryshojnë.

Një DOM node është njësi përbërëse e DOM-it.

Një Element në DOM është një node që shkruhet brenda një tag-u.

Shembull — DOM node & Element

<!DOCTYPE html>
<html>
  <head>
    <title>Texo</title>
  </head>
  <body>
    <!-- Page Body -->
    <h2>My Page</h2>
    <p id="content">Thank you for starting the React course!</p>
  </body>
</html>

Dokumenti i mësipërm i HTML përmban një hierarki me node, ku <html> është një node, dhe ka 2 children: <head> dhe <body>. Vetë body ka 3 children: një koment, një <h2> dhe një <p>.

Elementët në këtë dokument do të ishin: <html>, <head>, <title>, <body>, <h2>, <p> — pra të gjitha ato DOM node që janë tag-e.

Diferenca midis DOM node & Element

<p>
  <b>Mësoni React</b> në Texo
</p>

Nëse do të kontrollohej se sa nodes ka, paragrafi <p> përmban 2 child nodes: një element bold Mësoni React edhe një text node “në Texo”.

Nëse do të kontrollohej se sa elementë ka, paragrafi <p> përmban vetëm një element <b>Mësoni React</b>, sepse elementët janë tag-e.

Më shumë: MDN — Introduction to the DOM

Komponenti në React (React Component) janë njësi kodi përgjegjëse për shfaqjen e një “peme” elementësh në DOM.

Elementi në React (React Element) është përfaqësimi i një nyje në DOM (DOM node).

Për të ndërtuar komponentët në React, ne përdorim JSX

React docs — Introducing JSX

JSX që ne shkruajmë përfaqëson objekte. Babel, një JS compiler, merr kodin që ne e shkruajmë edhe e përkthen në kod të kuptueshëm për ambiente të ndryshme ku kodi ekzekutohet (p.sh. browsers të vjetërsive të ndryshme).

Kodi që ne shkruajmë në JSX:

const element = (
  <h1 className="greeting">
    Hello, world!
  </h1>
);

Babel e përkthen në:

const element = React.createElement(
  'h1',
  {className: 'greeting'},
  'Hello, world!'
);

E cila, e thjeshtëzuar për lexim nga ne, do të ishte:

const element = {
  type: 'h1',
  props: {
    className: 'greeting',
    children: 'Hello, world!'
  }
};

Pra këto objekte janë elementët e React (“React Elements”), të cilët — ndryshe nga elementët e DOM — janë shumë më efiçientë për t’u krijuar.

Shfaqja e elementit të React

Aplikacionet e ndërtuara në React tipikisht kanë vetëm një DOM node. Dikur në një dokument HTML supozojmë se ekziston një <div>: 

<div id="root"></div>

Ky <div> do të shërbejë si pika hyrëse / rrënja e aplikacionit të React. Kjo realizohet nëpërmjet ReactDOM.createRoot(), dhe elementi që do të shfaqet jepet si argument në root.render(): 

const root = ReactDOM.createRoot(
  document.getElementById('root')
);
const element = <h1>Hello, world</h1>;
root.render(element);
