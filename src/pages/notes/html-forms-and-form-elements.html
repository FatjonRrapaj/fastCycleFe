Understanding HTML Forms and Form Elements

Forms let users input data and send it to the server. Here’s a closer look at the form elements you’ll actually use.

Read on Dropbox instead →

HTML forms are a crucial component of web development as they allow users to input data and send it to the server for processing. In this article, we’ll take a closer look at different form elements and how to use them in HTML.

Input type: text

The input element with type="text" is one of the most basic form elements and is used for collecting simple text inputs: 

<div>
  <label for="firstName">Name:</label>
  <input
    id="firstName"
    name="name"
    type="text"
    placeholder="John"
    required
  />
</div>
<br />
<div>
  <label for="lastName">Surname:</label>
  <input
    id="lastName"
    name="surname"
    type="text"
    placeholder="Smith"
    required
  />
</div>

Here we have two text inputs — name and surname. The label associates each input with its text. The placeholder attribute hints at the expected input, and required ensures a value before submit.

Input type: password

type="password" collects password inputs. Characters are usually obscured for security: 

<div>
  <label for="password">Password:</label>
  <input id="password" name="password" type="password" />
</div>

In this example, a password input is associated with the label “Password.”

Input type: date

type="date" collects dates and typically shows a date picker / calendar: 

<div>
  <label for="birthDate">Birthdate:</label>
  <input id="birthDate" name="birthDate" type="date" />
</div>

Here a date input is associated with the label “Birthdate.”

Input type: tel

type="tel" is used for telephone numbers: 

<div>
  <label for="phone">Phone:</label>
  <input
    id="phone"
    name="phone"
    type="tel"
    placeholder="00355 68 68686 6886"
  />
</div>

The placeholder hints at the expected phone format.

Input type: number

type="number" collects numerical inputs: 

<div>
  <label for="weight">Weight (in kg):</label>
  <input
    id="weight"
    name="weight"
    type="number"
    step="10"
    max="300"
    min="50"
  />
</div>

step sets the interval between valid values — here 10, so multiples of 10. max is 300 and min is 50. Together they define a valid range — useful for something like weight. These attributes are optional; if omitted, browser defaults apply.

Radio buttons

Radio buttons work when there are multiple options but only one can be selected at a time — here, employment status: 

<div>
  <label for="unemployed">Unemployed: </label>
  <input id="unemployed" type="radio" name="employmentStatus" />
  <label for="student">Student: </label>
  <input id="student" type="radio" name="employmentStatus" />
  <label for="employed">Employed: </label>
  <input id="employed" type="radio" name="employmentStatus" />
</div>

Each option is an input with type="radio". The shared name groups them so only one can be selected. id connects each input to its label.

Select boxes

A select box (dropdown) is used when there are multiple options and one must be chosen — here, payment method: 

<div>
  <label for="paymentMethod">Payment Method:</label>
  <select id="paymentMethod" name="paymentMethod">
    <option value="cash">Cash</option>
    <option value="card">Card</option>
    <option value="paypal">PayPal</option>
  </select>
</div>

The control is a select. name identifies it on submit; id ties it to the label. Choices are option elements.

Checkboxes

Checkboxes allow one or more options to be selected — here, agreeing to terms: 

<div>
  <label for="term">Agree with terms </label>
  <input id="term" type="checkbox" name="terms" />
</div>

Use type="checkbox". name identifies it on submit; id connects it to the label.

Buttons

Two buttons — one to reset the form, one to submit: 

<button type="reset">Reset</button>
<button type="submit">Submit</button>

The type attribute sets the action. reset restores defaults; submit sends the form data to the server.
