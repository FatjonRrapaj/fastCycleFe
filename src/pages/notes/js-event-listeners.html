JavaScript Event Listeners

Event listeners let you watch for things like a button click and run a function in response — the foundation of dynamic, interactive pages.

Read on Dropbox instead →

Event listeners are an essential part of JavaScript programming. They allow you to listen for specific events, such as a button click, and respond by executing specific functions. That makes websites that can react to user input and give feedback. In this lesson we explore event listeners, why they matter, common examples, and how they pair with CSS animations.

What are event listeners?

Event listeners are functions attached to HTML elements — buttons, images, form fields, and more. When an event occurs (a mouse click, a key press), the attached function runs. It might update content on the page, or talk to a server.

Why use event listeners?

They make sites dynamic and interactive. Users can act; your code can respond in a meaningful way. That’s a core part of a good user experience.

Common event listeners in JavaScript

Some of the most used ones:

  1. onclick — detect a mouse click on an element.
  2. onmouseover — detect when the mouse moves over an element.
  3. onkeydown — detect when a keyboard key is pressed.
  4. onload — detect when an element has finished loading.
  5. onsubmit — detect when a form is submitted.

Examples

// Add an onclick event listener to a button
const button = document.getElementById("myButton");
button.onclick = function() {
  alert("Button was clicked!");
};

// Add an onmouseover event listener to an image
const image = document.getElementById("myImage");
image.onmouseover = function() {
  image.src = "newImage.jpg";
};

// Add an onkeydown event listener to the entire document
document.onkeydown = function(event) {
  console.log("Key pressed: ", event.code);
};

These show how listeners respond to user interaction with the page.

Practical example — interacting with HTML

HTML:

<!DOCTYPE html>
<html>
  <head>
    <title>Parcel Sandbox</title>
    <meta charset="UTF-8" />
    <link rel="stylesheet" href="./src/styles.css" />
  </head>
  <body>
    <h1 id="clickTitle">You clicked: 0 times</h1>
    <h1 id="clickHover">You Hovered: 0 times</h1>
    <div id="app"></div>
    <script src="src/index.js"></script>
  </body>
</html>

JavaScript:

const appDiv = document.getElementById("app");
const h1 = document.getElementById("clickTitle");
const h1Hover = document.getElementById("clickHover");

let clickCount = 0;
appDiv.onclick = function handleDivClick() {
  clickCount = clickCount + 1;
  h1.innerText = "You clicked: " + clickCount + " times";
};

let mouseOverCount = 0;
appDiv.onmouseover = function handleMouseOver() {
  mouseOverCount = mouseOverCount + 1;
  h1Hover.innerText = "You hovered: " + mouseOverCount + " times";
};

document.onkeydown = function onKeyDown(event) {
  console.log("Key pressed: ", event.code);
};

Three listeners at work:

  1. onclick on #app — each click increments clickCount and updates #clickTitle.
  2. onmouseover on #app — each hover increments mouseOverCount and updates #clickHover.
  3. onkeydown on document — logs event.code when a key is pressed.

Event listeners & CSS animations

CSS animations create dynamic motion with keyframes. You can control them with JavaScript event handlers.

Example: a #ball div with a ballAnimation that moves from left to right: 

#ball {
  width: 100px;
  height: 100px;
  background-color: red;
  border-radius: 50%;
  display: flex;
  justify-content: center;
  align-items: center;
  color: white;
  font-weight: bolder;
  animation: ballAnimation 1s linear;
  position: relative;
  animation-fill-mode: forwards;
  animation-play-state: paused;
}

@keyframes ballAnimation {
  0% {
    left: 0;
  }
  100% {
    left: calc(100vw - 100px);
  }
}

animation: ballAnimation 1s linear names the animation, sets a 1s duration, and a linear timing function. position: relative lets the ball move. animation-fill-mode: forwards keeps the end position. animation-play-state: paused means it won’t run until an event starts it.

In @keyframes ballAnimation, at 0% left is 0 (left edge). At 100% it’s calc(100vw - 100px) — right edge minus the ball’s width.

JS — interacting with CSS animations

Select the ball and its label:

const ball = document.getElementById("ball");
const textInsideBall = document.getElementById("ballText");

Read the animations on the element:

const ballAnimations = ball.getAnimations();

Track whether the animation has finished once: 

let isAnimationCompleted = false;

On click: play if it hasn’t finished; otherwise pause, reverse, and play again: 

ball.onclick = function onBallClick() {
  if (!isAnimationCompleted) {
    ballAnimations[0].play();
  } else {
    ballAnimations[0].pause();
    ballAnimations[0].reverse();
    ballAnimations[0].play();
  }
};

When the animation ends, mark it complete and update the label: 

ball.onanimationend = function onBallAnimationEnd() {
  isAnimationCompleted = true;
  textInsideBall.textContent = "Clicked!";
};

Conclusion

Combining CSS animations, keyframes, timing, duration, and JS event handlers lets you build interactive motion. This example moves a ball across the viewport and controls that motion with listeners — a pattern you can reuse on real product UIs.
