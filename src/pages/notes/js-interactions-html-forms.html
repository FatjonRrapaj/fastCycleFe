Introduction to JavaScript Interactions with HTML Forms

HTML forms collect data from the user. JavaScript adds interactivity — validation, capturing values, and reacting on submit.

Read on Dropbox instead →

When it comes to web development, HTML forms play a crucial role in collecting data from the user. And JavaScript is a powerful scripting language that can help you add interactivity and dynamic behaviour to your forms. In this article, we’ll explore the basics of JavaScript interactions with HTML forms, including form validation, capturing form data, and more.

A simple form

Let’s consider this HTML code:

<!DOCTYPE html>
<html>
  <head>
    <title>Parcel Sandbox</title>
    <meta charset="UTF-8" />
    <link rel="stylesheet" href="./src/styles.css" />
  </head>
  <body>
    <form id="form" class="formContainer">
      <label for="name">Name</label>
      <input id="name" name="name" type="text" />
      <p id="nameError"></p>
      <label for="email">Email</label>
      <input id="email" name="email" type="text" />
      <p id="emailError"></p>
      <label for="password">Password</label>
      <input id="password" name="password" type="text" />
      <p id="passwordError"></p>
      <button type="submit">Submit</button>
    </form>
    <script src="src/index.js"></script>
  </body>
</html>

Here we have a simple form, with ids on the form element and each input (plus matching error paragraphs).

Accessing form elements with JavaScript

The first step is to access the form elements. document.getElementById() can select the form and each field. Below we grab the form, the name / email / password inputs, and their error message elements: 

const form = document.getElementById("form");
const nameInput = document.getElementById("name");
const nameError = document.getElementById("nameError");
const emailInput = document.getElementById("email");
const emailError = document.getElementById("emailError");
const passwordInput = document.getElementById("password");
const passwordError = document.getElementById("passwordError");

Capturing the form submit event

Next, capture submit so you can run logic when the user sends the form. Use addEventListener on the form. event.preventDefault() stops the browser’s default navigation / full-page submit: 

form.addEventListener("submit", function (event) {
  event.preventDefault();
  const isFormValid = validateFormElements();
  if (isFormValid) {
    console.log({
      name: nameInput.value,
      email: emailInput.value,
      password: passwordInput.value
    });
    form.style.border = "none";
  } else {
    form.style.border = "4px solid red";
  }
});

Form validation

Validation checks that the user entered usable data before you treat the form as submitted. validateFormElements() inspects name, email, and password. If a field is empty or fails the rules (for example, email without @), an error message is shown and the form is not accepted. 

function validateFormElements() {
  const nameValue = nameInput.value;
  const emailValue = emailInput.value;
  const passwordValue = passwordInput.value;
  if (nameValue.length <= 0) {
    nameError.innerText = "*Name is required";
    return false;
  } else if (nameValue.length <= 1) {
    nameError.innerText = "*Name should be at least 2 characters";
    return false;
  } else {
    nameError.innerText = "";
  }
  if (emailValue.length <= 0) {
    emailError.innerText = "*Email is required";
    return false;
  } else if (!emailValue.includes("@")) {
    emailError.innerText = "*Email should have @ character to be vaild";
    return false;
  } else if (emailValue.length < 6) {
    emailError.innerText = "*Email should be at least 6 characters";
    return false;
  } else {
    emailError.innerText = "";
  }
  if (passwordValue.length <= 0) {
    passwordError.innerText = "*Password is required";
    return false;
  } else if (passwordValue.length < 6) {
    passwordError.innerText = "*Password should be at least 6 characters";
    return false;
  } else {
    const regex = /^(?=.*\d)(?=.*[!@#$%^&*])(?=.*[a-z])(?=.*[A-Z]).{6,}$/;
    if (!regex.test(passwordValue)) {
      passwordError.innerText =
        "*Password shoudl include at least one uppercase letter and one number and one special characer";
      return false;
    } else {
      passwordError.innerText = "";
    }
    return true;
  }
}

Input validation for the name field

Start by reading the name from nameInput.value: 

const nameValue = nameInput.value;

If the length is less than or equal to 0, the field is empty:

if (nameValue.length <= 0) {
  nameError.innerText = "*Name is required";
  return false;
}

If it’s greater than 0 but still only one character, require at least two: 

else if (nameValue.length <= 1) {
  nameError.innerText = "*Name should be at least 2 characters";
  return false;
}

Otherwise clear the error:

else {
  nameError.innerText = "";
}

Input validation for the email field

Read the email the same way:

const emailValue = emailInput.value;

Empty:

if (emailValue.length <= 0) {
  emailError.innerText = "*Email is required";
  return false;
}

Missing @:

else if (!emailValue.includes("@")) {
  emailError.innerText = "*Email should have @ character to be vaild";
  return false;
}

Too short (under 6 characters):

else if (emailValue.length < 6) {
  emailError.innerText = "*Email should be at least 6 characters";
  return false;
}

All checks passed — clear the message:

else {
  emailError.innerText = "";
}

Input validation for the password field

Same pattern with passwordInput.value:

const passwordValue = passwordInput.value;

Required:

if (passwordValue.length <= 0) {
  passwordError.innerText = "*Password is required";
  return false;
}

Minimum length:

else if (passwordValue.length < 6) {
  passwordError.innerText = "*Password should be at least 6 characters";
  return false;
}

If length is fine, require at least one number, one uppercase letter, and one special character via a regex: 

else {
  const regex = /^(?=.*\d)(?=.*[!@#$%^&*])(?=.*[a-z])(?=.*[A-Z]).{6,}$/;
  if (!regex.test(passwordValue)) {
    passwordError.innerText =
      "*Password shoudl include at least one uppercase letter and one number and one special characer";
    return false;
  } else {
    passwordError.innerText = "";
  }
  return true;
}

That’s the basics of validating form inputs in JavaScript. This example covers name, email, and password — the same ideas apply to other fields.
