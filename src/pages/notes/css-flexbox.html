CSS Flexbox

Flexbox është një model orientimi në CSS që lejon elementet e HTML-së të ndërveprojnë në drejtim vertikal ose horizontal — të zmadhohen, të zvogëlohen, dhe të rreshtohen sipas hapësirës.

Flexbox është një model orientimi në CSS që lejon që elementet e HTML-së të ndërveprojnë me mënyra të ndryshme gjatë orientimit të tyre në një faqe web. Ajo lejon që elementet të orientohen në një drejtim vertikal ose horizontal, të zmadhohen ose të zvogëlohen në varësi të hapësirës së disponueshme, dhe të ndërveprojnë me njëri-tjetrin në mënyra të ndryshme.

display: flex

Për të përdorur flexbox në një faqe HTML, duhet të caktoni që një element të jetë “kryesor” duke i vendosur stilin display: flex: 

.container {
  display: flex;
}

flex-direction: row

Pas kësaj, elementet e tjera që janë brenda kontainerit do të orientohen duke përdorur rregullat e flexbox-it. Për shembull, për të rregulluar elementet në drejtim horizontal, mund të përdorni rregullin flex-direction: row: 

.container {
  display: flex;
  flex-direction: row;
}

flex-direction: column

Për të orientuar elementet në drejtim vertikal, mund të përdorni rregullin flex-direction: column: 

.container {
  display: flex;
  flex-direction: column;
}

flex: 1 (ose flex: n)

Flexbox gjithashtu lejon që elementet të zmadhohen ose të zvogëlohen në varësi të hapësirës së disponueshme. Për të bërë këtë, mund të përdorni rregullin flex: 1 për të thënë që elementi duhet të zmadhohet sa më shumë të jetë e mundur: 

.item {
  flex: 1;
}

Më poshtë është një shembull i plotë i përdorimit të flexbox-it për të orientuar disa elemente në drejtim horizontal: 

<!doctype html>
<html>
<head>
  <style>
    .container {
      display: flex;
      flex-direction: row;
    }
    .item {
      flex: 1;
      border: 1px solid black;
      text-align: center;
    }
  </style>
</head>
<body>
  <div class="container">
    <div class="item">Elementi</div>
    <div class="item">Elementi 2</div>
    <div class="item">Elementi 3</div>
  </div>
</body>
</html>

Kjo do të shfaqë një faqe HTML me tre elemente që janë orientuar në drejtim horizontal dhe zmadhohen sa më shumë të jetë e mundur në hapësirën e disponueshme.

justify-content

Kjo rregullon se si elementet janë rregulluar në hapësirën e lënë bosh në drejtimin kryesor të flexbox-it. Për shembull, për të rregulluar elementet në qendër të hapësirës së lirë, mund të përdorni justify-content: center: 

.container {
  display: flex;
  justify-content: center;
}

align-items

Kjo rregullon se si elementet janë rregulluar në hapësirën e lënë bosh në drejtimin kryq (cross axis) të flexbox-it. Për shembull, për të rregulluar elementet në qendër, mund të përdorni align-items: center: 

.container {
  display: flex;
  align-items: center;
}

align-self

Kjo tregon se si një element i veçantë është orientuar në hapësirën e lënë bosh në drejtimin kryq. Për shembull, për të orientuar një element në qendër, mund të përdorni align-self: center: 

.item {
  align-self: center;
}

flex-wrap

Kjo rregullon se si elementet orientohen kur nuk ka më hapësirë të mjaftueshme në drejtimin kryesor. Për shembull, për të lejuar që elementet të “rreshtohen” në vijim, mund të përdorni flex-wrap: wrap: 

.container {
  display: flex;
  flex-wrap: wrap;
}

Shembull me justify-content dhe align-items

Më poshtë është një shembull i plotë me tre div-e që orientohen brenda një div-i të quajtur container, duke përdorur justify-content dhe align-items: 

<!doctype html>
<html>
<head>
  <style>
    .container {
      display: flex;
      justify-content: space-between;
      align-items: center;
      border: 1px solid black;
      width: 80%;
      margin: 0 auto;
    }
    .item {
      flex: 1;
      border: 1px solid black;
      text-align: center;
    }
  </style>
</head>
<body>
  <div class="container">
    <div class="item">Elementi 1</div>
    <div class="item">Elementi 2</div>
    <div class="item">Elementi 3</div>
  </div>
</body>
</html>

Kjo do të shfaqë një div me tre elemente brenda saj. justify-content: space-between lë hapësirë të barabartë në mes tyre, dhe align-items: center i orientojnë në qendër të hapësirës së lirë.

Shembull me align-self

Më poshtë është një shembull i përdorimit të align-self për të orientuar një element në qendër të hapësirës së lirë: 

<!DOCTYPE html>
<html>
  <head>
    <style>
      body {
        height: 100%;
      }
      .container {
        display: flex;
        width: 80%;
        background-color: red;
        height: 50vh;
      }
      .item {
        border: 4px solid white;
        text-align: center;
        align-self: center;
      }
    </style>
  </head>
  <body>
    <div class="container">
      <div class="item">Elementi 1</div>
    </div>
  </body>
</html>

Në këtë shembull, elementi është i rregulluar në qendër të hapësirës së lirë duke përdorur align-self: center.
