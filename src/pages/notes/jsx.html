JSX

JSX qëndron për JavaScript XML dhe na lejon të shkruajmë elementë HTML dhe t’i vendosim në DOM lehtësisht. 

export default function App() {
  return (
    <div className="App">
      <h1>Hello CodeSandbox</h1>
      <h2>Start editing to see some magic happen!</h2>
    </div>
  );
}

Pjesa e kodit brenda return() është JSX dhe do të përdoret gjithmonë për të krijuar komponentë në React.

JSX mund të kthejë tekst të thjeshtë

const element = <div>this is some plain text</div>

JSX mund të kthejë shprehje

const course = 'Texo';
const element = <div>Kursi quhet {course}</div>

JSX mund të kthejë shprehje nëpërmjet funksioneve

function addNumbers(a,b){
  return a+b
}
const result = <p>4 + 5 is {addNumbers(4+5)}</p>

JSX mund të përdoret si JS expression

Pra ka brenda një if-else si kod normal JS: 

function getGreeting(user) {
  if (user) {
    return <h1>Hello, {formatName(user)}!</h1>;
  }
  return <h1>Hello, Stranger.</h1>;
}

Ju mund të stiloni elementë me JSX

funtion Box(){
  return <div style={{width:'100px',height:'100px'}}/>
}

Ju mund t’i prezantoni komponentët e React si JSX

function BoxContainer(){
  return <div> <Box/> </div>
}
