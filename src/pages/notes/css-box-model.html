CSS Box Model

Mendojeni CSS Box Model si një “kuti” që mbështjell përmbajtjen (Content) — me Padding, Border dhe Margin.

Mendojeni CSS Box Model si një “kuti” që mbështjell përmbajtjen (Content). CSS Box Model përbëhet nga Padding, Border dhe Margin.

Border

Në CSS, border është një vijë që rrethon kontentin. Konsideroni shembullin e mëposhtëm:

Është vendosur një paragraf pa asnjë stilim, por nëse do të vendoset një border, do të duket kështu:

Kodi për të vendosur border:

p {
  border-width: 3px;
  border-color: red;
  border-style: solid;
}

Për të specifikuar një border në CSS duhen 3 argumenta: border-width, border-color, border-style.

border-width: Trashësia e vijës. Mund të specifikohet për çdo krah me border-top-width, border-bottom-width, border-left-width dhe border-right-width.

border-color: Ngjyra e vijës. Mund të specifikohet për çdo krah me border-top-color, border-bottom-color, border-left-color dhe border-right-color.

border-style: Lloji i vijës. Mund të jetë solid për një vijë të plotë, dashed për vijë të ndërprerë etj.

Sintaksa e shkurtuar për border:

border: 1px solid blue;

Ku argumenti i parë (1px) është për trashësinë, argumenti i dytë (solid) për llojin edhe i treti (blue) për ngjyrën.

Padding

Padding është distanca midis kontentit edhe border. Konsideroni shembullin e mëposhtëm:

Në linjën e parë është vendosur stilimi për border, që t’a bëjë padding më të dukshëm.

Kodi për të vendosur padding:

p {
  padding-top: 4px;
  padding-bottom: 50px;
  padding-left: 100px;
  padding-right: 200px;
}

padding-<drejtimi>: specifikon padding sipas drejtimit.

Sintaksa e shkurtuar për padding — nëse do t’a shkruanim me një rresht: 

padding: 4px 200px 50px 100px;

Ku në fillim specifikohet padding-top, pastaj right, bottom edhe left (sipas drejtimit të akrepave të orës).

Nëse padding-top = padding-bottom dhe padding left = padding-right, mund të shkruhet: 

padding: 60px 20px;

Ku argumenti i parë (60px) është për vertical padding edhe argumenti i dytë (20px) është për horizontal padding.

Nëse padding është i njëjtë në të gjitha anët mund të shkruhet padding: 10px.

Margin

Margin është distanca nga border me elementët e tjerë (ose parent). Konsideroni shembullin e mëposhtëm:

2 linjat e para të kodit janë për të vendosur padding edhe margin.

Kodi për margin:

p {
  margin-top: 20px;
  margin-bottom: 10px;
  margin-left: 200px;
  margin-right: 150px;
}

Sintaksa e shkurtuar për margin është e njëjtë me atë të padding, përveç se në vend të padding vendoset margin. Për shembull: 

margin: 20px 150px 10px 200px;
margin: 10px 20px;
margin: 10px;
