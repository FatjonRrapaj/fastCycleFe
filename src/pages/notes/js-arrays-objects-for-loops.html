JS Arrays, Objects & For Loops

Arrays and objects are essential data structures in JavaScript for storing collections of data. In this lesson we cover the basics — accessing elements, filling empty collections, and traversing arrays with loops.

Read on Dropbox instead →

Arrays in JavaScript

An array in JavaScript is a collection of elements of any data type. Elements within an array are identified by their position or index in the array, which starts from 0. Arrays can store elements of different data types, including numbers, strings, objects, and other arrays.

For example, the following code defines an array arr that contains elements of different data types: 

const arr = ["Janar", 10, "Mars", "Prill", "Maj", "Qershor", "Korrik"];

Accessing elements within arrays

To access an element within an array, use square bracket notation and the index of the element you want. For example, this accesses the first element in arr: 

console.log(arr[0]);

Adding elements to empty arrays

Empty arrays can be created by initializing with []. To add elements, use square bracket notation and specify the index of the new element: 

const emptyArray = [];
emptyArray[4] = 10;
emptyArray[10] = 100;
console.log(emptyArray);

Objects in JavaScript

An object in JavaScript is a collection of key-value pairs. The keys are strings, and the values can be of any data type. Objects are similar to arrays in that they store multiple pieces of data, but unlike arrays they use keys instead of indexes to identify elements.

For example, this defines an object obj with three key-value pairs: 

const obj = {
  name: "Genti",
  age: 24,
  height: 185
};

Accessing elements within objects

To access a property, use dot notation and the key. For example, the height of obj: 

console.log(obj.height);

Adding elements to empty objects

Empty objects can be created with {}. Add properties with dot notation and a new key-value pair: 

const emptyObj = {};
emptyObj.grades = [4, 4, 4, 4, 4];
console.log(emptyObj);

Arrays of objects

In JavaScript we can store multiple objects in a single array. Each object represents one entity with its own properties. Declare an array and initialize it with objects: 

const person = {
  image: "https://www.google.com/images",
  name: "Robert",
  status: "Money In",
  amount: 999999999
};

const person2 = {
  image: "https://www.google.com/images",
  name: "Jim",
  status: "Money In",
  amount: 999999999
};

const person3 = {
  image: "https://www.google.com/images",
  name: "Joshua",
  status: "Money In",
  amount: 999999999
};

const info = [person, person2, person3];

console.log(info);

Here, person, person2, and person3 are stored in info. Access an object with its index — the first is 0: 

console.log(info[0]);

Arrays of objects are a powerful way to store and manipulate many related entities in one structure.

For loops in JavaScript

For loops repeat a block of code a set number of times. They’re commonly used to traverse arrays and operate on each element.

A for loop has three parts: an initialization statement, a condition, and an iteration statement. Initialization runs once before the loop. The condition is checked before each iteration — if true, the body runs; if false, the loop ends. The iteration statement runs after each pass and updates the loop control variable.

Example — traverse an array:

const testArray = [1, 2, 3, 4, 5];
for (let i = 0; i < testArray.length; i++) {
  console.log(testArray[i]);
}

The loop starts with let i = 0. While i < testArray.length is true, the body runs. i++ increments i after each iteration.

Another common use is finding the sum and average of array elements: 

const notatENxenesit1 = [4, 4, 4, 4, 10, 10, 7, 5, 4, 4, 4, 4, 10, 10, 10, 10, 10];
let shumaENotave = 0;
for (let i = 0; i < notatENxenesit1.length; i++) {
  shumaENotave = notatENxenesit1[i] + shumaENotave;
}
console.log("The sum of the array is: ", shumaENotave);
console.log("The average of the array is: ", shumaENotave / notatENxenesit1.length);

The sum accumulates in shumaENotave. The average is the sum divided by the array length.
